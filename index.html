ATEM Tally · Board einrichten

Luma Media · ESP32-C3 SuperMini
Dieser Browser kann keine Boards flashen.
Zum Flashen braucht es Chrome oder Edge auf einem Computer — Safari und iPhone können das nicht. Die Adressen unten kannst du trotzdem ablesen.

1 Was soll auf das Board?

Diese Leuchte bekommt —
Die Adresse folgt der Kameranummer: Router-Netz + 210 + Kamera. Sie liegt damit über dem Bereich, den der Router selbst vergibt, und kann nie doppelt vorkommen. In Streamee trägst du bei dieser Kamera genau diese Adresse ein.

2 Firmware aufspielen

Board per USB anstecken, klicken, im Fenster den Port auswählen. Beim ersten Mal alles löschen wählen. Meldet sich kein Port: BOOT gedrückt halten, USB einstecken, BOOT loslassen, neu versuchen.
Ein Board, das schon läuft, musst du dafür nicht anstecken — dort geht ein Update bequemer über http://<Adresse der Leuchte>/update vom iPhone aus.

3 Einstellungen übertragen

Schickt WLAN, ATEM-IP und Kameranummer über dasselbe USB-Kabel ins Board und startet es neu. Die Daten liegen danach im Board, nicht auf dieser Seite und nicht im Internet.

Bereit.

Wenn etwas klemmt

  1. Kein Port in der Liste: anderes USB-Kabel probieren — viele Kabel können nur laden.
  2. Port da, aber keine Antwort: Der Arduino-Monitor darf nicht gleichzeitig offen sein, er belegt den Port.
  3. Nach dem Flashen pulsiert die LED violett: Das Board hat noch kein WLAN — genau dafür ist Schritt 3 da.
  4. Oranger Doppelblitz: Der ATEM lehnt ab, weil zu viele Geräte gleichzeitig mit ihm sprechen. Eine Verbindung schließen.

Datenschutz

Diese Seite hat keinen Server im Rücken. WLAN-Name, Passwort, ATEM-IP und Kameranummer bleiben im Browser und gehen ausschließlich über das USB-Kabel an das Board — sie werden nirgendwo hochgeladen. Das Passwort wird nicht gespeichert; die übrigen Felder merkt sich der Browser lokal, damit du sie beim nächsten Board nicht neu tippen musst (löschbar über die Website-Daten deines Browsers).

Zum Flashen lädt die Seite ein Hilfsprogramm von jsDelivr (cdn.jsdelivr.net). Dabei erfährt dieser Dienst deine IP-Adresse. Sonst werden keine Daten an Dritte übertragen.
